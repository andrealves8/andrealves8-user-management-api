# User Management API — CRUD com Spring Boot & PostgreSQL

Este projeto é uma API REST desenvolvida com Spring Boot, focada no cadastro e gerenciamento de usuários.  
Inclui operações completas de CRUD (Create, Read, Update, Delete), integração com PostgreSQL, validação de dados e arquitetura limpa — ideal para estudos ou aplicações reais.

---

## 🚀 Tecnologias Utilizadas

- Java 21+
- Spring Boot 4
- Spring Data JPA
- Hibernate
- PostgreSQL
- Lombok
- Validation API
- Maven

---

## 📂 Funcionalidades

- Criar usuários  
- Listar todos os usuários  
- Buscar usuário por ID  
- Atualizar dados  
- Excluir usuário  
- Validação automática (@NotBlank, @Email, etc.)
